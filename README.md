# learn

Go 语言学习笔记仓库：按主题拆分目录，每个主题下都有一个可独立运行的 `main.go` 小示例（部分示例位于带 `go.mod` 的子目录中），代码中附带大量中文注释，记录语法要点、使用方式以及与 Java 等语言的对比。

## 环境要求

- Go 1.18 及以上（`16.泛型` 用到泛型，Go 1.18 正式引入）
- 仓库根目录没有 `go.mod`，绝大多数示例可以直接 `go run` 单个文件
- `19.文件/filedemo`、`20.反射/reflect` 是各自独立的 module（含 `go.mod`），需在对应目录下运行

## 运行示例

在仓库根目录运行指定章节：

```bash
go run ".\1.基础语法\main.go"
```

或进入章节目录后运行：

```bash
cd 1.基础语法
go run main.go
```

带 `go.mod` 的章节（`19.文件/filedemo`、`20.反射/reflect`）需要进入对应目录后按模块运行：

```bash
cd 19.文件\filedemo
go run .
```

> `19.文件/filedemo` 的示例使用相对路径读写同目录下的测试文件，必须在 `filedemo` 目录内运行。

## 说明

- 【注意】本仓库的内容**仍在持续完善中**，部分章节（如 `21.并发`）目前仅为占位骨架，后续会继续补充。
- 示例输出多使用 `log` 包，日志会带上时间戳并输出到标准错误，属于正常现象。
- [15.接口/epic](./15.接口/epic/epic.go) 是一个演示用的子包（`package epic`）。由于仓库根目录没有 `go.mod`，`15.接口/main.go` 中引用该包的代码以注释形式保留，需要时可初始化模块后再启用。
- 各章示例彼此独立，可单独阅读和运行，建议按目录序号顺序学习。
