# learn

Go 语言学习笔记仓库：按主题拆分目录，每个目录的 `main.go` 是一个可独立运行的小示例，代码中附带大量中文注释，记录语法要点、使用方式以及与 Java 等语言的对比。

## 环境要求

- Go 1.18 及以上（`16.泛型` 用到泛型，Go 1.18 正式引入）
- 本仓库未使用 `go.mod`，所有示例通过 `go run` 直接运行单个文件

## 运行示例

在仓库根目录运行指定章节：

```bash
go run ".\1.基础语法\main.go"
```

或进入章节目录后运行：

```bash
cd 1.基础语法
go run main.go
```

## 说明

- 示例输出多使用 `log` 包，日志会带上时间戳并输出到标准错误，属于正常现象。
- [15.接口/epic](./15.接口/epic/epic.go) 是一个演示用的子包（`package epic`）。由于仓库没有 `go.mod`，`15.接口/main.go` 中引用该包的代码以注释形式保留，需要时可初始化模块后再启用。
- 各章示例彼此独立，可单独阅读和运行，建议按目录序号顺序学习。
